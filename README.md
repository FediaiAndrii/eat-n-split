# Eat-N-Split

A simple React application for tracking shared expenses and splitting bills with friends. Built as part of Jonas Schmedtmann's Ultimate React Course.

🔗 **Live Demo:** [Eat-N-Split](https://fediaiandrii.github.io/eat-n-split)

## Features

- Add new friends to the list.
- Select a friend from the list to split a bill.
- Calculate who owes whom based on the total bill, your expense, and who is paying.
- Automatically update and track the balance for each friend.
- Close the split bill calculation form.

## Tech Stack

- React (Create React App)
- CSS

## Running Locally

To run this project on your local machine:

1. Clone the repository.
2. Install dependencies: `npm install`
3. Start the development server: `npm start`
